Akka eebbifamuu eeggachuun — yeroo tokko bakka ati hin eeggatin — maal fakkaata? Akkam bulteessan, isin hundi kan Afaan Oromoo dubbiftan — bakka kamittuu jirtan, ani gammade isin as jirtan.

Yesuus tuuta namootaa argee, gaara ol ba'ee taa'e, barattootni isaa dhufan. Inni jalqabee barsiisuu: "Eebbifamoo kan hiyyeessa hafuuraa, mootummaan samii kan isaanii ta'eef. Eebbifamoo kan gaddan, isaan jajjabeessamaniif. Eebbifamoo kan laafaa, isaan lafa dhaalaa ta'eef. Eebbifamoo kan beelaa fi dheebuu qajeelummaa, isaan quufaniif. Eebbifamoo kan garaa galchii qabdu, kan qulqulluu garaa, kan nagaa godhan, fi kan qajeelummaa irratti dhiibaman — mootummaan samii kan isaanii ta'eef."

Eebbifamoonni kunne keessaa kamtu amma atiif dubbata? Eebbifamni jireenya kee keessatti maal fakkaata?

Yoo kana Afaan Oromootiin dubbiftan — bakka kamittuu addunyaa kanaa — yeroo muraasa fudhattanii Jonathan nagaa gaafachuu dandeessu?

*Jechoota Macaafa Qulqulluu kan as keessa jiran kana bakka interneetaa kanaaf hiikaman.*
